# 橘座 - 资产找回业务演进与关键节点 (Business Evolution Timeline)

| 时间 | 事件 | 对业务逻辑的影响 |
| :--- | :--- | :--- |
| 早期探索期 | 尝试通过技术手段直接追踪黑客链上地址，研究智能合约漏洞。 | 发现“黑客反杀”在实操中不仅技术门槛极高，且面临非法侵入计算机系统的法律风险。彻底放弃纯技术反制路线。 |
| 业务成型期 | 介入首批杀猪盘与资金盘维权案例，发现大量资金最终流入CEX（如币安、欧易、火币）。 | 确立了**“CEX拦截战法”**。认识到中心化交易所的KYC机制是去中心化世界里唯一的执法抓手。业务重心从“破解密码”转向“锁定法币出入金通道”。 |
| 标准化期 | 面对海量受害者的咨询，团队人力不堪重负，且接了一些“死局”案子导致客户纠纷。 | 建立了**“胜率漏斗模型”**。制定了严格的拒单标准（不见CEX不接、进混币器不接、金额太小不接）。将业务从“感情援助”完全剥离为“商业概率计算”。 |
| 风险规避期 | 在协助报案过程中，遇到受害者本身资金涉黑，险些连累团队。 | 引入**“客户反向尽调机制”**。确立了“只接干净单子”的红线，防范合规风险。 |
| 近期演化 | CEX风控收紧，骗子开始使用更复杂的OTC（场外交易）网络和承兑商洗钱。 | 完善**“施压与妥协博弈模型”**。由于跨国司法划拨越来越难，将重点转向锁定骗子或承兑商身份后，利用其规避刑事处罚的心理进行“退赃换谅解”的谈判。 |
